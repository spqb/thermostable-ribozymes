# Data

| file | description |
|---|---|
| `azoarcus.csv` | Azoarcus wild type: `name`, `sequence` (197 nt, with the `GUG`/`G` flanks) and `dot_bracket`, the consensus secondary structure (square brackets: pseudoknot) |
| `dca_model_lambert.dat` | Potts (DCA) model of the group I intron family from Lambert et al.; adabmDCA 2.0 text format (`J i j a b value` for i < j, `h i a value`), L = 193, alphabet `-ACGU` |
| `dca_training_msa.fasta` | multiple sequence alignment of group I introns (Rfam RF00028, Azoarcus first) on which the DCA model was trained: 817 sequences, 193 columns, alphabet `-ACGU` |
| `lambert_dataset.csv` | sequences generated by several models and tested by Lambert et al. |
| `experiment.csv` | sequences tested in this work, with measured activities |
| `mnist_toy_samples.npz` | samples of the MNIST toy example (Fig. 1) |

## `lambert_dataset.csv`

All sequences generated by several models and tested by Lambert et al. (24,220 rows).

| column | |
|---|---|
| `name` | sequence name in Lambert et al. |
| `model` | generative model (`DCA_T=1`, `DCA T=$0.3$`, `DCA-SB`, `SB`, `VAE`, `RDM`, `profile`, `SB-3D`, `BPR`, `BPR-3D`, `CHI`) |
| `sequence` | 197 nt |
| `activity_37`, `activity_60` | activity `log10(f_sel/f_ref)` at 37 °C (condition `T37C`) and at 60 °C (condition `T60C_myseq`); empty = no detected activity, or not tested at 60 °C |
| `matched` | the 3,429 sequences of the matched dataset (tested at both temperatures, activity detected at 37 °C, at least 11 reference reads at 60 °C) used for Fig. 2 and SI Figs. 2–3 |
| `start_id` | 1–10 for the ten starting sequences used in this work, empty otherwise |

The condition `T37C_myseq` (re-measurement at 37 °C of the sequences tested at 60 °C) and the low-Mg condition of the
original database are not included.

## `experiment.csv`

One row per synthesised sequence (3855 in total).

| column | |
|---|---|
| `id` | `start<N>_<group>_<k>` for designs, `noise_<k>`, `overlap_<k>` |
| `group` | `lowDCA_lowSB` (1500), `lowDCA_highSB` (500), `highDCA_lowSB` (500), `noise` (1000), `overlap` (355) |
| `start_id` | starting sequence (designs only) |
| `sequence` | 197 nt |
| `activity_37`, `activity_60` | raw activity `log10(f_sel/f_ref)` at 37 °C and 60 °C, `NaN` = not detected. Not yet normalised, see the main README |
| `ref_count_*`, `sel_count_*` | normalised read counts of the control (`ref`) and reacted (`sel`) samples |
| `legacy_id` | identifier in the files returned by the experiment (for `noise` and `overlap`: name of the sequence in Lambert et al.) |

Groups: the three design groups sample different regions of the (`H_gen`, `S_sb`) plane (Table I of the paper);
`noise` are >100 substitutions away from Azoarcus and give the background; `overlap` are high-activity sequences
included in every pool to normalise the experiments.

## `mnist_toy_samples.npz`

For each region `lowH_highS`, `lowH_lowS`, `highH_highS`, `highH_lowS`: `<region>__samples` (binary 28×28 images
flattened), `<region>__Hgen` (RBM energy) and `<region>__p8` (probability of class "8"); `start` is the starting digit.
